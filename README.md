🔹 Título
🎮 React Jogo das Palavras
📌 Descrição

Um jogo de adivinhação de palavras desenvolvido com React e TypeScript, inspirado em jogos populares de palavras como Wordle e Termo (jogo de adivinhação diário). O objetivo do jogo é desafiar o usuário a descobrir uma palavra oculta com base em tentativas e dicas visuais — uma forma divertida de testar vocabulário e lógica de dedução.

🚀 Tecnologias

✔ React
✔ TypeScript
✔ Vite
✔ CSS

🧠 Como jogar

Uma palavra secreta é gerada

O jogador tenta adivinhar essa palavra em um número limitado de tentativas

Cada tentativa dá um feedback visual indicando se as letras estão na posição correta ou não

O objetivo é descobrir a palavra antes que as chances acabem

📈 Objetivos do projeto

Este projeto foi criado com o intuito de:

✔ Praticar React com TypeScript
✔ Explorar estado e lógica de jogo no front-end
✔ Construir uma aplicação jogável e interativa
✔ Criar uma demonstração concreta para um portfólio de desenvolvedor

▶️ Como rodar localmente

Clone o repositório

git clone https://github.com/Isac2006/React-jogo-das-palavras.git


Entre na pasta do projeto

cd React-jogo-das-palavras


Instale as dependências

npm install


Inicie o servidor de desenvolvimento

npm run dev
